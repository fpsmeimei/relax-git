## 核心实现

### AI Service 代码

```typescript
async chat(message: string, conversationHistory: Array) {
  // 构建对话上下文
  const messages = [
    { role: 'system', content: '你是专业的电影推荐助手...' },
    ...conversationHistory, // 历史对话（最近10轮）
    { role: 'user', content: message },
  ];

  // 调用智谱AI
  const response = await this.client.chat.completions.create({
    model: 'glm-4-flash',
    messages,
    temperature: 0.6,
    max_tokens: 300,
  });

  return response.choices[0]?.message?.content;
}
```

### 技术亮点

- **上下文记忆**：保留最近10轮对话，实现连贯对话
- **错误处理**：余额不足、限流等场景的降级方案
- **参数优化**：temperature=0.6（平衡创造性），max_tokens=300
