## Part 1: React/Next.js（20 题）

### Q1: useState 和 useEffect 区别？⭐⭐⭐⭐⭐

**答**: useState 管理状态，useEffect 处理副作用 **Relax-Git**: `hooks/useRepository.ts` -
useState 存数据，useEffect 获取数据

### Q2: useCallback 和 useMemo 区别？⭐⭐⭐⭐

**答**: useCallback 缓存函数，useMemo 缓存值 **Relax-Git**: `FileTree.tsx` -
useMemo 缓存扁平化树，useCallback 缓存点击函数

### Q3: useEffect 依赖数组的坑？⭐⭐⭐⭐⭐

**答**: 1) 遗漏依赖拿到旧值 2) 对象依赖无限循环 3) 内部修改依赖 **Relax-Git**:
`useWebSocket.ts` - 依赖 url，返回清理函数

### Q4: React 生命周期 Hooks 替代？⭐⭐⭐⭐

**答**: 挂载 useEffect(fn,[])，更新 useEffect(fn,[deps])，卸载 return 清理
**Relax-Git**: 所有 hooks 都用 useEffect 管理生命周期

### Q5: Custom Hooks 好处？⭐⭐⭐⭐⭐

**答**: 逻辑复用、代码组织、测试方便、关注点分离 **Relax-Git**: `useAuth.ts` `useRepository.ts`
`useDebounce.ts`

### Q6: React 18 新特性？⭐⭐⭐⭐

**答**: Concurrent 渲染、自动批处理、Transitions、Suspense **Relax-Git**: 使用 Suspense 包裹异步组件

### Q7: React 组件通信方式？⭐⭐⭐⭐

**答**: Props、Callback、Context、状态管理(Zustand)、EventBus **Relax-Git**:
Zustand 管理全局状态 (auth/repos)

### Q8: React 性能优化？⭐⭐⭐⭐⭐

**答**: React.memo、useCallback、useMemo、虚拟列表、懒加载、避免内联对象、稳定 key、状态下放
**Relax-Git**: FileTree 用 memo+callback+虚拟列表

### Q9: Next.js SSR vs SSG？⭐⭐⭐⭐⭐

**答**: SSR 每次服务器渲染(实时数据)，SSG 构建时生成(静态内容)
**Relax-Git**: 仓库页用 SSR，文档页用 SSG

### Q10: App Router vs Pages Router？⭐⭐⭐⭐

**答**: App Router 默认 Server Component，文件路由更灵活 **Relax-Git**: 使用 App Router (app/目录)

### Q11: Next.js Image 优化？⭐⭐⭐

**答**: 自动 WebP、响应式、懒加载、占位符、CDN **Relax-Git**: 仓库封面用 next/image

### Q12: Next.js API Routes？⭐⭐⭐

**答**: app/api/ 目录创建 API 端点 **Relax-Git**: API Routes 转发到 NestJS

### Q13: Virtual DOM 是什么？⭐⭐⭐

**答**: JS 对象表示 DOM，diff 后只更新变化部分 **Why**: 减少 DOM 操作，提升性能

### Q14: React Fiber 是什么？⭐⭐⭐

**答**: React 16 新架构，支持可中断渲染 **Why**: 提升用户体验，避免阻塞

### Q15: React key 的作用？⭐⭐⭐⭐

**答**: 帮助 React 识别元素变化，优化 diff **注意**: 不要用 index，用稳定的 id

### Q16: 什么是 HOC？⭐⭐⭐

**答**: Higher-Order Component，接收组件返回新组件 **现在**: 大部分被 Hooks 替代

### Q17: React.memo 和 useMemo 区别？⭐⭐⭐⭐

**答**: React.memo 缓存组件，useMemo 缓存值 **Relax-Git**: FileItem 用 React.memo

### Q18: useRef 的使用场景？⭐⭐⭐

**答**: 1) 访问 DOM 2) 存储不触发渲染的值 **Relax-Git**: 文件上传组件获取 input 元素

### Q19: useReducer vs useState？⭐⭐⭐

**答**: 复杂状态逻辑用 useReducer，简单用 useState **示例**: 多个相关状态用 useReducer

### Q20: React Context 性能问题？⭐⭐⭐

**答**: Context 变化所有消费者重渲染 **解决**: 拆分 Context、用 memo、状态管理库

## Part 2: TypeScript（10 题）

### Q21: interface vs type？⭐⭐⭐⭐⭐

**答**: interface 可合并/继承，type 可联合/交叉 **Relax-Git**: 对象用 interface，联合类型用 type

### Q22: 泛型是什么？⭐⭐⭐⭐⭐

**答**: 类型参数化，保持类型安全 **Relax-Git**: `ApiResponse<T>` `useFetch<T>()`

### Q23: 联合类型 vs 交叉类型？⭐⭐⭐⭐

**答**: 联合 | (或)，交叉 & (且) **示例**: `type Status = 'A'|'B'` vs `type AB = A & B`

### Q24: 类型守卫？⭐⭐⭐⭐

**答**: typeof、instanceof、in、自定义类型断言 **Relax-Git**: 判断 error 类型

### Q25: 常用工具类型？⭐⭐⭐⭐⭐

**答**: Partial、Pick、Omit、Required、Readonly、Record **Relax-Git**: `Omit<User,'password'>`
隐藏密码

### Q26: any vs unknown vs never？⭐⭐⭐

**答**: any 不安全，unknown 安全的 any，never 永不返回 **建议**: 避免 any，用 unknown

### Q27: 类型断言 as？⭐⭐⭐

**答**: 告诉 TS 具体类型 **示例**: `user as User`

### Q28: 枚举 enum？⭐⭐⭐

**答**: 定义常量集合 **Relax-Git**: `enum Status { READY, FAILED }`

### Q29: 装饰器？⭐⭐⭐

**答**: 修改类/方法/属性 **Relax-Git**: NestJS 大量使用 `@Controller()` `@Get()`

### Q30: tsconfig 关键配置？⭐⭐⭐

**答**: strict、target、module、paths **Relax-Git**: strict: true，paths 配置别名

## Part 3: NestJS/Node.js（15 题）

### Q31: 依赖注入原理？⭐⭐⭐⭐⭐

**答**: IoC 容器管理依赖，构造函数自动注入 **Relax-Git**:
`constructor(private prisma: PrismaService)`

### Q32: NestJS 模块化？⭐⭐⭐⭐

**答**: @Module 装饰器，imports/providers/exports **Relax-Git**: UsersModule 导入 PrismaModule

### Q33: 中间件 vs 守卫 vs 拦截器 vs 管道？⭐⭐⭐⭐⭐

**答**:

- 中间件: 请求前处理 (日志)
- 守卫: 权限验证
- 拦截器: 响应转换
- 管道: 数据验证/转换 **Relax-Git**: AuthGuard 验证 JWT

### Q34: NestJS 生命周期？⭐⭐⭐

**答**: onModuleInit → onApplicationBootstrap → onModuleDestroy **Relax-Git**:
Worker 启动时连接 Redis

### Q35: Prisma vs TypeORM？⭐⭐⭐⭐

**答**: Prisma 类型安全/开发体验好，TypeORM 功能全 **Relax-Git**: 用 Prisma

### Q36: Node.js 事件循环？⭐⭐⭐⭐

**答**: timers → IO → check → close，微任务优先 **理解**: 异步非阻塞

### Q37: Stream 流？⭐⭐⭐

**答**: 处理大数据，边读边处理 **Relax-Git**: Worker 处理大文件

### Q38: Buffer 是什么？⭐⭐⭐

**答**: 二进制数据缓冲区 **用途**: 文件读写、网络传输

### Q39: 进程 vs 线程？⭐⭐⭐

**答**: 进程独立内存，线程共享内存 **Node.js**: 单线程 + 事件循环

### Q40: Cluster 模块？⭐⭐⭐

**答**: 多进程利用多核 CPU **Relax-Git**: PM2 管理多进程

### Q41: pm2 原理？⭐⭐⭐⭐

**答**: 进程管理器，自动重启、负载均衡、日志 **Relax-Git**: ecosystem.config.js

### Q42: JWT 认证流程？⭐⭐⭐⭐⭐

**答**: 登录 → 签发 token → 请求带 token → 验证 **Relax-Git**: Passport + JWT Strategy

### Q43: WebSocket 实现？⭐⭐⭐⭐

**答**: Socket.IO 封装，支持房间、事件、降级 **Relax-Git**: Gateway 处理实时通知

### Q44: Redis 使用场景？⭐⭐⭐⭐⭐

**答**: 缓存、队列、Session、分布式锁 **Relax-Git**: Bull MQ 队列

### Q45: 异常过滤器？⭐⭐⭐

**答**: @Catch() 装饰器统一处理异常 **Relax-Git**: HttpExceptionFilter

### Q46: 数据库索引原理？⭐⭐⭐⭐

**答**: Atomic 原子、Consistent 一致、Isolated 隔离、Durable 持久 **Relax-Git**: Prisma transaction

### Q48: SQL 注入防御？⭐⭐⭐⭐

### Q49: Monorepo 优势？⭐⭐⭐⭐⭐

**答**: 代码复用、统一依赖、统一构建、类型共享 **Relax-Git**: Turborepo 管理 apps + libs

### Q50: 微服务 vs 单体？⭐⭐⭐⭐

**答**: 微服务独立部署/扩展，单体简单 **Relax-Git**: 单容器部署，Worker 独立进程
