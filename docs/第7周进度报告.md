## WebSocket架构

### 后端WebSocket网关

```typescript
// 用户加入聊天室
@SubscribeMessage('join:chat')
async handleJoinChat(client, data: { chatId }) {
  await client.join(`chat:${data.chatId}`);
}

// 广播新消息
emitChatMessageNew(chatId, message) {
  this.server.to(`chat:${chatId}`).emit('chat:message:new', message);
}
```

### 前端监听事件

```typescript
useEffect(() => {
  const unsubscribe = on('chat:message:new', message => {
    const isSelf = user.id === message.senderId;
    updateMessages(message);
```

## 技术难点

### 1. 消息去重

**问题**：WebSocket推送和HTTP响应导致消息重复  
**解决**：基于消息ID过滤

```typescript
const seen = new Set();
messages.filter(msg => {
  if (seen.has(msg.id)) return false;
  seen.add(msg.id);
  return true;
});
```

### 2. 断线重连

**问题**：网络中断后连接丢失  
**解决**：Socket.IO自动重连 + 手动重新加入房间
