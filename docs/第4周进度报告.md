## 数据库设计

### 核心数据表

```typescript
User          - 用户信息（用户名、密码、头像）
Chat          - 聊天会话（私聊/群聊）
Message       - 消息记录
Friendship    - 好友关系（双向）
FriendRequest - 好友申请
```

### Prisma Schema

```typescript
model User {
  id         String    @id @default(cuid())
  username   String    @unique
  password   String    // bcrypt 哈希
  avatar     String?
  isActive   Boolean   @default(true)
  createdAt  DateTime  @default(now())
}
```

## 用户认证实现

### 注册接口

```typescript
POST /api/auth/register
请求：{ "username": "testuser", "password": "test123" }
响应：{ "id": "...", "username": "testuser", "token": "..." }
```

### 登录接口

```typescript
POST /api/auth/login
请求：{ "username": "testuser", "password": "test123" }
响应：{ "access_token": "...", "user": {...} }
```

**安全机制**：

- ✅ 密码bcrypt加密（10轮哈希）
- ✅ JWT令牌认证（7天有效期）
- ✅ 用户名唯一性校验
