## 核心功能特性

### 1. 基础结构

```typescript
interface CommentStructure {
  // 主评论
  mainComments: {
    id: string;
    content: string;
    author: { id: string; username: string; avatar?: string };
    createdAt: string;
    likes: number;
    isLiked: boolean;
    replies?: Reply[]; // 次评论（回复）
  }[];
}
```

**关键点：**

- 主评论 + 次评论（回复）的两层结构
- 次评论扁平化存储在主评论的 `replies` 数组中
- 支持"A 回复 B"的显示格式

### 2. 排序逻辑

```typescript
// 主评论排序：点赞数降序 → 时间升序
const sortedComments = [...comments].sort((a, b) => {
  const likeDiff = (b.likesCount || 0) - (a.likesCount || 0);
  if (likeDiff !== 0) return likeDiff;
  return new Date(a.createdAt).getTime() - new Date(b.createdAt).getTime();
});

// 次评论排序：点赞数降序
const sortedReplies = [...replies].sort((a, b) => (b.likesCount || 0) - (a.likesCount || 0));
```

**排序策略：**

- 主评论：热度优先（点赞数），同热度按时间正序
- 次评论：纯热度排序（点赞数降序）

### 3. 展开/折叠回复

```typescript
const [expandedReplies, setExpandedReplies] = useState<Set<string>>(new Set());

const toggleRepliesExpansion = (commentId: string) => {
  setExpandedReplies(prev => {
    const newSet = new Set(prev);
    if (newSet.has(commentId)) {
      newSet.delete(commentId);
    } else {
      newSet.add(commentId);
    }
    return newSet;

// 默认显示前2条回复
```

**实现要点：**

- 使用 `Set` 管理展开状态
- 默认显示前2条回复
- 超过2条显示"查看更多"按钮

## 技术实现要点

### 1. 跳转定位与高亮闪烁

#### 核心实现

```typescript
// 状态管理
const [highlightedCommentId, setHighlightedCommentId] = useState<string | null>(null);
const commentRefs = useRef<Record<string, HTMLDivElement | null>>({});

// 高亮逻辑
useEffect(() => {
  if (highlightCommentId && comments.length > 0) {
    let targetCommentId: string | null = null;
    let isReply = false;

    // 查找目标评论（主评论或次评论）
    for (const comment of comments) {
      if (comment.id === highlightCommentId) {
        targetCommentId = comment.id;
        break;
      }
      if (comment.replies?.some(reply => reply.id === highlightCommentId)) {
        targetCommentId = comment.id; // 主评论ID
        isReply = true;
        break;
      }
    }

    if (targetCommentId) {
      // 如果是次评论，先展开主评论
      if (isReply) {
        setExpandedReplies(prev => new Set(prev).add(targetCommentId!));
      }

      setHighlightedCommentId(highlightCommentId);

      // 平滑滚动到目标
      setTimeout(() => {
        const targetElement = commentRefs.current[highlightCommentId];
        if (targetElement) {
          targetElement.scrollIntoView({
            behavior: 'smooth',
            block: 'center',
            inline: 'nearest',
          });
        }
      }, 100);

      // 1秒后移除高亮
      const timer = setTimeout(() => {
        setHighlightedCommentId(null);
      }, 1000);
      return () => clearTimeout(timer);
    }
  }
  return undefined;
}, [highlightCommentId, comments]);
```

### 2. 乐观更新

#### 点赞操作

```typescript
const handleLike = async (commentId: string, isReply = false) => {
  const snapshot = localData; // 保存快照用于回滚

  try {
    if (likingIds.has(commentId)) return;
    setLikingIds(prev => new Set(prev).add(commentId));

    // 1. 立即更新UI（乐观更新）
    const optimisticData = {
      ...localData,
      comments: localData.comments.map(c => {
        if (c.id === commentId && !isReply) {
          return { ...c, likes: c.likes + (c.isLiked ? -1 : 1), isLiked: !c.isLiked };
        }
        // 处理次评论...
        return c;
      }),
    };
    updateLocalData(() => optimisticData);

    // 2. 调用API
    const res = c.isLiked
      ? await apiClient.delete(`/comments/${commentId}/like`)
      : await apiClient.post(`/comments/${commentId}/like`);

    // 3. 使用服务端返回的真实数据修正
    const correctedData = {
      ...optimisticData,
      comments: optimisticData.comments.map(c => {
        if (c.id === commentId) {
          return { ...c, likes: res.data.likesCount, isLiked: res.data.liked };
        }
        return c;
      }),
    };
    updateLocalData(() => correctedData);
  } catch (error) {
    // 4. 失败时回滚
    restoreLocalData(snapshot);
    toast({ title: '点赞失败', variant: 'destructive' });
  } finally {
    setLikingIds(prev => {
      const s = new Set(prev);
      s.delete(commentId);
      return s;
    });
  }
};
```

#### 删除操作

```typescript
const handleDelete = async (commentId: string, isReply = false) => {
  if (!confirm('确认删除该评论？')) return;

  const snapshot = [...comments]; // 保存快照

  try {
    // 1. 乐观更新：立即从列表移除
    const optimistic = comments.filter(c => c.id !== commentId);
    setComments(optimistic);

    // 2. 调用API
    await apiClient.delete(`/comments/${commentId}`);
    toast({ title: '已删除' });
  } catch (error) {
    // 3. 失败时回滚
    setComments(snapshot);
    toast({ title: '删除失败', variant: 'destructive' });
  }
};
```

**乐观更新最佳实践：**

- ✅ 先更新UI，再调用API
- ✅ 保存操作前的快照用于回滚
- ✅ 使用 `Set` 防止重复操作
- ✅ 服务端数据修正客户端状态
- ✅ 失败时完整回滚

```typescript
const formatCount = (value?: number) => {
  const num = Number(value ?? 0);
  if (Number.isNaN(num)) return '0';
  if (num >= 10000) return `${(num / 10000).toFixed(1).replace(/\.0$/, '')}万`;
  if (num >= 1000) return `${(num / 1000).toFixed(1).replace(/\.0$/, '')}k`;
  return `${num}`;
};
```
