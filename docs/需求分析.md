## 1. 引言

### 1.1 编写目的

本文档旨在全面分析"基于人工智能的电影推荐对话系统"的需求，明确系统功能、性能、界面等方面的具体要求，为系统设计和开发提供依据。

### 1.2 项目背景

随着流媒体平台的兴起，用户面临海量电影资源的选择困难。传统的电影推荐系统往往基于固定的标签和评分，缺乏个性化和互动性。本项目旨在利用人工智能技术，开发一个能够通过自然语言对话的方式，为用户提供智能化、个性化电影推荐的系统。

### 1.3 定义与缩略语

| 术语      | 解释                                            |
| --------- | ----------------------------------------------- |
| AI        | Artificial Intelligence，人工智能               |
| LLM       | Large Language Model，大语言模型                |
| NLP       | Natural Language Processing，自然语言处理       |
| WebSocket | 一种在单个TCP连接上进行全双工通信的协议         |
| API       | Application Programming Interface，应用程序接口 |
| JWT       | JSON Web Token，身份认证令牌                    |

## 2. 项目概述

### 2.1 系统目标

开发一个基于人工智能的电影推荐对话系统，实现以下核心目标：

1. **智能对话**：通过自然语言与用户交互，理解用户的电影偏好
2. **个性化推荐**：根据对话内容，提供符合用户口味的电影推荐
3. **社交互动**：支持用户之间分享推荐、实时聊天
4. **友好界面**：提供简洁、美观、易用的 Web 界面

### 2.2 应用场景

**场景1：新用户寻求推荐**

```
用户：我想看一部科幻电影
AI：您喜欢硬科幻还是软科幻？有没有特别喜欢的导演？
用户：喜欢诺兰的电影
AI：推荐您观看《星际穿越》，这是诺兰的经典硬科幻作品...
```

**场景2：基于观影历史推荐**

```
用户：我刚看完《盗梦空间》，觉得很棒
AI：既然您喜欢《盗梦空间》，推荐您看《记忆碎片》，同样是诺兰导演...
```

**场景3：好友分享推荐**

```
用户A：我发现了一部很棒的电影《肖申克的救赎》
系统：分享给好友 → 用户B 收到推荐通知
用户B：看到好友推荐，点击查看详情
```

### 2.3 用户群体

- **主要用户**：18-35岁的年轻观影群体
- **特点**：熟悉互联网产品，追求个性化推荐，乐于社交分享
- **需求**：快速找到感兴趣的电影，获取可信赖的推荐

## 3. 功能需求

### 3.1 用户管理模块

#### 3.1.1 用户注册

- **功能描述**：新用户创建账号
- **输入**：用户名、密码
- **处理逻辑**：
  - 检查用户名唯一性
  - 密码加密存储（bcrypt）
  - 生成唯一用户 ID
- **输出**：注册成功提示，自动跳转登录

#### 3.1.2 用户登录

- **功能描述**：已注册用户登录系统
- **输入**：用户名、密码
- **处理逻辑**：
  - 验证用户名密码
  - 生成 JWT 令牌
  - 记录登录状态
- **输出**：登录成功，跳转主界面

#### 3.1.3 头像管理

- **功能描述**：用户上传和修改头像
- **输入**：图片文件（PNG/JPEG/WEBP）
- **处理逻辑**：
  - 验证文件类型和大小（< 5MB）
  - 上传到 Cloudinary CDN
  - 更新用户头像 URL
- **输出**：头像更新成功

### 3.2 AI 对话模块

#### 3.2.1 智能对话

- **功能描述**：用户与 AI 进行自然语言对话
- **输入**：用户文本消息
- **处理逻辑**：
  1. 采集对话上下文（最近10轮）
  2. 调用智谱 AI API
  3. 生成 AI 回复
  4. 返回给用户
- **输出**：AI 文本回复

#### 3.2.2 上下文记忆

- **功能描述**：AI 记住之前的对话内容
- **实现方式**：
  - 客户端存储对话历史
  - 每次请求携带最近 10 轮对话
  - 基于用户 ID 隔离存储
- **效果**：AI 能理解"这部电影"等指代词

#### 3.2.3 智能推荐

- **功能描述**：根据用户偏好推荐电影
- **推荐策略**：
  - 基于对话内容分析用户喜好
  - 考虑类型、导演、演员等因素
  - 提供推荐理由
- **输出格式**：
  ```
  推荐电影：《星际穿越》
  导演：克里斯托弗·诺兰
  类型：科幻、剧情
  推荐理由：硬核科幻设定，诺兰式叙事...
  ```

### 3.3 实时聊天模块

#### 3.3.1 好友系统

- **添加好友**：
  - 搜索用户（用户名模糊匹配）
  - 发送好友申请（可附加留言）
  - 接受/拒绝申请
  - 双向好友关系建立

- **好友列表**：
  - 显示所有好友
  - 显示在线状态
  - 未读消息提醒

#### 3.3.2 实时消息

- **发送消息**：
  - 文本消息（支持换行）
  - 实时推送（WebSocket）
  - 消息状态（发送中、已送达、已读）

- **接收消息**：
  - 实时接收通知
  - 消息气泡展示
  - 未读数统计

#### 3.3.3 消息管理

- **消息历史**：
  - 分页加载历史消息
  - 上拉加载更多
  - 消息时间戳

- **消息操作**：
  - 清空聊天记录（单边删除）
  - 标记已读
  - 消息搜索（未来）

### 3.4 AI 助手模块

#### 3.4.1 虚拟 AI 好友

- **功能描述**：系统内置的 AI 助手，作为特殊好友存在
- **特点**：
  - 置顶显示，始终在线
  - 独立的对话存储
  - 支持电影推荐、闲聊等

#### 3.4.2 快速访问

- **功能描述**：从聊天室快速打开 AI 对话
- **实现方式**：
  - 点击 AI 助手头像
  - 跳转到专用 AI 聊天页面
  - 保留对话历史

## 4. 非功能性需求

### 4.1 性能需求

| 指标         | 要求               |
| ------------ | ------------------ |
| 页面加载时间 | < 2秒              |
| AI 响应时间  | < 5秒              |
| 消息推送延迟 | < 500ms            |
| 并发用户数   | 支持 100+ 在线用户 |

### 4.2 可用性需求

- **响应式设计**：支持 PC、平板、手机
- **浏览器兼容**：Chrome、Firefox、Safari、Edge
- **无障碍访问**：支持键盘导航、屏幕阅读器

### 4.3 安全性需求

- **身份认证**：基于 JWT 的无状态认证
- **密码安全**：bcrypt 加密存储
- **API 安全**：CORS 限制、请求频率限制
- **数据隔离**：用户数据严格隔离

### 4.4 可维护性需求

- **代码规范**：使用 TypeScript 保证类型安全
- **模块化设计**：前后端分离，模块解耦
- **错误日志**：详细的错误日志记录
- **文档完善**：API 文档、部署文档

## 5. 数据需求

### 5.1 数据模型

#### 用户表 (User)

```typescript
{
  id: string; // 主键
  username: string; // 用户名（唯一）
  uid: string; // 用户唯一标识
  password: string; // 密码哈希
  avatar: string // 头像 URL
    ? isActive
    : boolean; // 账号状态
  isOnline: boolean; // 在线状态
  createdAt: DateTime;
  updatedAt: DateTime;
}
```

#### 聊天会话表 (Chat)

```typescript
{
  id: string; // 主键
  type: 'DIRECT' | 'GROUP'; // 会话类型
  name: string // 群聊名称
    ? directKey
    : string // 私聊唯一键
      ? createdAt
      : DateTime;
  updatedAt: DateTime;
}
```

#### 消息表 (Message)

```typescript
{
  id: string; // 主键
  chatId: string; // 所属会话
  senderId: string; // 发送者 ID
  content: string; // 消息内容
  type: 'TEXT' | 'IMAGE' | 'SYSTEM';
  isRead: boolean; // 是否已读
  readAt: DateTime // 阅读时间
    ? createdAt
    : DateTime;
}
```

#### 好友关系表 (Friendship)

```typescript
{
  id: string; // 主键
  userId: string; // 用户 A
  friendId: string; // 用户 B（好友）
  createdAt: DateTime;
}
```

#### 好友申请表 (FriendRequest)

```typescript
{
  id: string; // 主键
  fromUserId: string; // 申请人
  toUserId: string; // 被申请人
  status: 'PENDING' | 'ACCEPTED' | 'REJECTED';
  message: string // 申请留言
    ? createdAt
    : DateTime;
  updatedAt: DateTime;
}
```

### 5.2 数据存储

- **关系型数据库**：PostgreSQL 16
  - 用户数据、聊天记录、好友关系
  - 优点：事务支持、复杂查询、数据一致性

- **缓存层**：Redis 7
  - 会话管理、在线状态、消息队列
  - 优点：高性能、支持 Pub/Sub

- **文件存储**：Cloudinary CDN
  - 用户头像、图片消息
  - 优点：全球加速、自动优化

### 5.3 数据量估算

**假设用户规模：1000 用户**

| 数据类型 | 估算量     | 存储空间 |
| -------- | ---------- | -------- |
| 用户数据 | 1,000 条   | ~1 MB    |
| 聊天会话 | 5,000 条   | ~5 MB    |
| 消息记录 | 100,000 条 | ~100 MB  |
| 好友关系 | 10,000 条  | ~1 MB    |
| 总计     | -          | ~107 MB  |

## 7. 外部接口

### 7.1 智谱 AI API

- **接口地址**：https://open.bigmodel.cn/api/paas/v4/
- **认证方式**：API Key
- **请求频率**：每分钟 60 次（免费版）
- **主要接口**：
  - `/chat/completions` - 聊天对话

### 7.2 Cloudinary CDN

- **接口地址**：https://api.cloudinary.com/v1_1/
- **认证方式**：Cloud Name + API Key + API Secret
- **主要功能**：
  - 图片上传
  - 自动优化
  - 格式转换

## 9. 约束与限制

### 9.1 技术约束

- **AI 模型**：仅支持智谱 AI，不支持其他 LLM
- **浏览器**：需支持 ES2020 及 WebSocket
- **移动端**：通过响应式设计支持，暂无原生 App

### 9.2 业务约束

- **免费用户限制**：
  - AI 对话：每天 100 次
  - 好友数量：最多 50 个
  - 消息存储：最近 30 天

- **付费用户（未来）**：
  - 不限 AI 对话次数
  - 不限好友数量
  - 永久消息存储

### 9.3 法律约束

- 遵守《网络安全法》
- 用户隐私保护（GDPR）
- 内容审核机制
