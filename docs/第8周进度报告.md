## 好友系统流程

### 添加好友

```
1. 搜索用户（用户名模糊匹配）
2. 发送好友申请（可附加留言）
3. 对方收到WebSocket通知
4. 接受/拒绝申请
5. 建立双向好友关系
6. 自动创建私聊会话
```

### 智能逻辑

- ✅ 检测双向申请，自动通过
- ✅ 防止重复添加好友
