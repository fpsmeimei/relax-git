## 第三页：需求分析

### 项目背景

在信息爆炸的时代，用户面临海量电影资源却难以快速找到符合自己口味的作品。传统搜索和分类浏览效率低下，用户常陷入选择困难。

### 核心需求

**1. 智能对话推荐**

- 自然语言交互，理解用户模糊描述
- 基于对话历史提供个性化推荐
- 快速响应用户需求

**2. 视觉化呈现**

- 电影海报、评分、导演等信息清晰展示
- 统一的主题设计，提供沉浸式体验
- 响应式布局，支持多设备

**3. 收藏管理**

- 一键收藏喜欢的电影
- 支持分页浏览收藏夹
- 快速查看详情和相似推荐

**4. 实时准确**

- 集成真实电影数据库
- 只展示真实存在的电影
- AI 快速响应（< 2秒）

### 目标用户

- 电影爱好者
- 选择困难症患者
- 需要快速找片的忙碌人群

## 第四页：系统设计介绍

### 技术栈

**前端**

- 框架：Next.js 15 (React 19)
- 语言：TypeScript
- UI：Tailwind CSS + Radix UI
- 主题：Nord 色系
- 图标：Lucide React

**后端**

- 框架：NestJS
- 语言：TypeScript
- 数据库：PostgreSQL + Prisma ORM
- 认证：NextAuth.js (JWT)
- 实时通信：Socket.IO

**AI & 外部 API**

- DeepSeek v3.2 API
- TMDB 电影数据库 API

### 核心模块

**1. AI 对话模块**

- 集成 DeepSeek v3.2
- **三种对话模式**（平衡性能与质量）：
  - **探索模式**：Temperature 1.0, Max Tokens 4096
  - **思考模式**：Temperature 1.1, Max Tokens 4096（优化速度）
  - **聊天模式**：Temperature 1.0, Max Tokens 4096
- 60 秒超时控制，支持深度输出
- 30 条对话历史上下文

**2. 电影解析模块**

- 正则提取电影信息
- 格式：《中文片名》(年份) [English Name] - 豆瓣评分
- 提取导演、推荐理由等

**3. TMDB 集成模块**

- 根据英文片名搜索电影
- 获取高清海报 URL
- 查询失败自动隐藏

**4. 收藏管理模块**

- 添加/删除/查询收藏
- 分页加载（每页 6 部）
- 持久化存储海报 URL

## 第八页：功能介绍 - 三种 AI 对话模式

**官网级 AI 体验**

### 模式概览

系统提供三种专业对话模式，完全对标 DeepSeek 官网配置：

| 模式        | Temperature | Max Tokens | 适用场景             |
| ----------- | ----------- | ---------- | -------------------- |
| **🔍 探索** | 1.0         | 4096       | 发现新片、多元化推荐 |
| **🎭 思考** | 1.3         | 8192       | 深度影评、艺术分析   |
| **💬 聊天** | 1.0         | 4096       | 轻松对话、分享感受   |

### 探索模式

**特点**：主动发现，推荐 4-6 部电影

- 优先推荐用户可能没看过的优质作品
- 包含新片、冷门佳作、独立电影
- 涵盖不同类型、年代、地域

### 思考模式

**特点**：深度分析，推荐 2-4 部精选

- 详细解读主题、镜头语言、音乐
- 结合影史地位和导演风格
- 支持超长深度影评（最多 8192 tokens）

### 聊天模式

**特点**：自然对话，推荐 2-3 部

- 口语化表达，像朋友聊天
- 理解用户情感和观影场景
- 推荐自然融入对话

### 技术优化

- **上下文增强**：保留最近 30 条对话
- **超时优化**：60 秒超时支持长输出
- **官网对标**：Temperature 和 Max Tokens 完全一致

## 第九页：功能介绍 - 智能推荐策略

**AI 推荐机制**

### DeepSeek 提示词优化

**推荐策略**

- **积极推荐**：用户询问时主动推荐相关电影
- **格式严格**：每部必须包含完整信息
- **真实电影**：只推荐真实存在的电影
- **信息准确**：导演、年份、评分必须正确

**推荐场景**

- 用户问某部电影 → 介绍后推荐 3 部相似
- 用户要推荐 → 直接推荐 4-5 部
- 用户聊天讨论 → 适时推荐 2-3 部相关

### 推荐格式示例

```
《肖申克的救赎》(1994) [The Shawshank Redemption] - 豆瓣9.7
导演：弗兰克·德拉邦特
经典中的经典，关于希望和自由的永恒之作。
```

### 智能特性

- 自动提取英文片名用于查询海报
- 查询失败自动隐藏卡片
- 基于对话历史理解上下文

## 最后一页：存在的问题与改进计划

### 当前存在的问题

**1. 数据来源局限**

- 仅依赖 TMDB 数据库
- 部分冷门电影海报缺失

**2. AI 幻觉问题**

- DeepSeek 偶尔推荐不存在的电影
- 通过 TMDB 验证 + 自动隐藏缓解

**3. 推荐算法单一**

- 仅基于 AI 对话
- 缺少协同过滤等传统算法

**4. 移动端适配不足**

- 主要针对桌面端设计
- 小屏幕操作体验待优化

---

### 改进计划

**短期（1-2 个月）**

- 集成豆瓣 API 作为备选数据源
- 优化移动端响应式布局
- 添加收藏标签分类（已看/想看）

**中期（3-6 个月）**

- 基于用户收藏历史的协同过滤
- 添加社交功能（好友推荐、影评）

- 支持多轮深度对话和语音交互
- 图片识别（上传剧照查电影）
