# 📦 Relax-Git 包管理

本目录用于存放第三方包、工具和独立的可复用组件。

## 📁 目录结构

```
packages/
├── ui-components/     # UI 组件库
├── utils/            # 工具函数库
├── types/            # TypeScript 类型定义
└── configs/          # 配置文件模板
```

## 🎯 使用场景

- 可复用的 UI 组件
- 通用工具函数
- 类型定义文件
- 配置文件模板
- 第三方包的本地修改版本
