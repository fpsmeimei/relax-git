# 🎯 Relax-Git 示例项目

本目录包含用于演示 Relax-Git 功能的示例项目。

## 📁 示例项目列表

### [SimpleBlog](simpleblog/)
现代化博客系统，展示复杂的 Git 协作流程：
- 多分支开发模式
- 功能分支管理
- 代码审查流程
- 快照功能演示

### [Real-GitHub](real-github/)
GitHub 风格的代码托管平台示例：
- 仓库管理
- 分支可视化
- 协作开发场景

## 🚀 使用方法

每个示例项目都包含独立的 README 文档，请查看具体项目目录了解详细使用方法。
